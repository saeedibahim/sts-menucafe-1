# Cafe Menu System

نظام قائمة رقمي كامل للمقاهي مع صفحة قائمة للعملاء ولوحة تحكم إدارية.

## المميزات

### للعملاء (صفحة القائمة)
- 🎨 تصميم عصري وأنيق بألوان دافئة
- 📱 متجاوب مع جميع الأجهزة (موبايل، تابلت، ديسكتوب)
- 🔍 بحث فوري في القائمة
- 🏷️ تصفية حسب الفئات
- ✨ تأثيرات Glassmorphism وجزيئات متحركة
- 🌐 دعم كامل للغة العربية (RTL)

### لوحة التحكم الإدارية
- 📊 إحصائيات شاملة
- 📂 إدارة الفئات (إضافة، تعديل، حذف)
- 🍽️ إدارة الأصناف (إضافة، تعديل، حذف)
- ⚙️ إعدادات المقهى (الاسم، الشعار، واتساب، إنستقرام)
- 🔐 نظام تسجيل دخول آمن

## التقنيات المستخدمة

- **Backend**: PHP + MySQL
- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **الخط**: IBM Plex Sans Arabic
- **التصميم**: Glassmorphism, Floating Particles

## متطلبات التشغيل

- PHP 7.4 أو أحدث
- MySQL 5.7 أو أحدث
- خادم ويب (Apache أو Nginx)

## التثبيت والإعداد

### 1. إعداد قاعدة البيانات

```sql
-- إنشاء قاعدة البيانات
CREATE DATABASE cafe_menu CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

-- استيراد البيانات
USE cafe_menu;
SOURCE database.sql;
```

### 2. إعداد ملف الاتصال بقاعدة البيانات

افتح ملف `api/config.php` وقم بتحديث بيانات الاتصال:

```php
define('DB_HOST', 'localhost');      // عنوان الخادم
define('DB_NAME', 'cafe_menu');      // اسم قاعدة البيانات
define('DB_USER', 'root');           // اسم المستخدم
define('DB_PASS', '');               // كلمة المرور
```

### 3. رفع الملفات

ارفع جميع الملفات إلى خادم الويب الخاص بك.

### 4. تسجيل الدخول للوحة التحكم

- **الرابط**: `your-domain.com/admin-login.html`
- **البريد الإلكتروني**: `admin@cafe.com`
- **كلمة المرور**: `admin123`

⚠️ **مهم**: قم بتغيير بيانات تسجيل الدخول الافتراضية فوراً!
